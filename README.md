# Password Generate

Небольшая консольная утилита на Go для генерации случайных паролей с тремя уровнями сложности. Пароли генерируются с использованием криптографически безопасного источника случайных чисел (`crypto/rand`), а каждая кандидатура проверяется на соответствие требованиям выбранного уровня.

## Возможности

- 🔐 Криптостойкая генерация через `crypto/rand` (без `math/rand`)
- 🎚 Три уровня сложности с разной длиной и набором символов
- ✅ Валидация готового пароля: повторная генерация, если требования не выполнены
- 🚫 Отсутствие внешних зависимостей — только стандартная библиотека Go

## Уровни сложности

| Флаг      | Длина | Символы                                                        | Требования к паролю                              |
|-----------|-------|----------------------------------------------------------------|--------------------------------------------------|
| `-easy`   | 8     | `a-z`, `0-9`                                                   | минимум одна строчная буква и одна цифра         |
| `-medium` | 12    | `a-z`, `A-Z`, `0-9`                                            | строчные, заглавные буквы и цифры                |
| `-hard`   | 20    | `a-z`, `A-Z`, `0-9`, `!@#$*_=+?`                               | строчные, заглавные, цифры и спецсимволы         |

## Требования

- Go 1.27 или новее (проект использует современный синтаксис, например `for range n`)

## Установка и сборка

```bash
git clone <URL репозитория>
cd password_generate
go build -o password_generate .
```

Или запустить без сборки:

```bash
go run . <complexity>
```

## Использование

```bash
./password_generate <complexity>
```

где `<complexity>` — один из флагов: `-easy`, `-medium`, `-hard`.

### Примеры

```bash
$ ./password_generate -easy
Level -easy: k3m9x2pa (length: 8)

$ ./password_generate -medium
Level -medium: aB3kQ9xWz2Lm (length: 12)

$ ./password_generate -hard
Level -hard: Tq4#xL9=mZ2kP7!rB5+W (length: 20)
```

При неверном аргументе или его отсутствии выводится сообщение об использовании:

```bash
$ ./password_generate
Usage: password_generate <complexity> (options: -easy, -medium, -hard)
```

## Как это работает

1. `main` читает единственный аргумент командной строки — флаг сложности.
2. `generatePassword` выбирает длину и набор символов для уровня, затем в цикле генерирует пароль посимвольно с помощью `crypto/rand.Int`.
3. Сгенерированная кандидатура проверяется функцией `validateEasyPassword` / `validateMediumPassword` / `validateHardPassword`. Если проверка не пройдена, пароль генерируется заново.
4. Готовый пароль выводится в stdout вместе с уровнем и длиной.
