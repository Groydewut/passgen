# Password Generate

Простая консольная утилита на Go для генерации безопасных паролей с тремя уровнями сложности.

Проект использует криптографически стойкий генератор случайных чисел `crypto/rand` и проверяет каждую сгенерированную кандидатуру на соответствие требованиям выбранного уровня.

## Что умеет проект

- Генерировать пароли уровня `-easy`, `-medium` и `-hard`
- Использовать криптографически безопасную случайность вместо `math/rand`
- Валидировать пароль после генерации и повторять попытки при несоответствии
- Не иметь внешних зависимостей: всё работает только со стандартной библиотекой Go

## Уровни сложности

| Флаг | Длина | Допустимые символы | Условия валидации |
| --- | --- | --- | --- |
| `-easy` | 8 | `a-z`, `0-9` | минимум одна строчная буква и одна цифра |
| `-medium` | 12 | `a-z`, `A-Z`, `0-9` | минимум одна строчная, одна заглавная буква и одна цифра |
| `-hard` | 20 | `a-z`, `A-Z`, `0-9`, `!@#$*_=+?` | минимум одна строчная, одна заглавная, одна цифра и один специальный символ |

## Требования

- Go 1.27.1 или новее

## Установка и запуск

Клонировать проект:

```bash
git clone <repository-url>
cd password_generate
```

Собрать бинарник:

```bash
go build -o passgen .
```

Запустить без сборки:

```bash
go run . -easy
```

## Использование

```bash
./passgen <complexity>
```

Где `<complexity>` — один из аргументов:

- `-easy`
- `-medium`
- `-hard`

### Примеры

```bash
$ ./passgen -easy
k3m9x2pa

$ ./passgen -medium
aB3kQ9xWz2Lm

$ ./passgen -hard
Tq4#xL9=mZ2kP7!rB5+W
```

Если аргумент не передан или передан неверно, программа завершится с подсказкой:

```bash
$ ./passgen
Usage: passgen <complexity> (options: -easy, -medium, -hard)
```

## Как это работает

1. Программа принимает один аргумент командной строки — уровень сложности.
2. В зависимости от выбранного уровня выбирается набор допустимых символов и длина пароля.
3. `generatePassword` в цикле создаёт случайные значения символов через `rand.Int(rand.Reader, ...)`.
4. Сгенерированный пароль проверяется функцией `validateEasyPassword`, `validateMediumPassword` или `validateHardPassword`.
5. Если проверка не пройдена, генерируется новая попытка.
6. После успешной валидации пароль выводится в стандартный вывод.

## Примечание

Этот проект подходит для простых задач генерации паролей в локальном окружении и демонстрирует работу с безопасной генерацией случайных значений в Go.
